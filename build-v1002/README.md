# Lulu Finity 1.0.2

Hotfix de interfaz para ventanas no maximizadas.

El parche limita correctamente la segunda fila del grid principal, mantiene el contenido central como región desplazable y conserva el scroll independiente de navegación, búsqueda y diálogos. Se aplica sobre la fuente reproducible de Lulu Finity 1.0.1.

```bash
python build-v1002/apply-v1002.py app
python build-v1002/test-v1002.py app
```
