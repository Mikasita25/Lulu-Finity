# Lulu Finity 0.33.0 — Automatizaciones

Esta versión conserva el diseño y la organización visual de Lulu e incorpora un motor único para reaccionar a eventos del LIVE.

Incluye reglas por regalos, follows, likes, compartidos, suscripciones, entradas y comentarios; acciones combinables de TTS, chat, sonidos, alertas y webhooks; metas del LIVE; y pantallas independientes para alertas, metas y estadísticas de regalos.

Los webhooks son deliberadamente genéricos para permitir Streamer.bot, servidores locales y futuras integraciones sin convertir la interfaz en una colección de plugins separados.
