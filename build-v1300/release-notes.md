## Lulu Finity 1.3.0 — acciones visuales por color de ruleta

En **Juegos > Ruleta de 8 colores** ahora puedes configurar una acción visual independiente para cada color:

- **Sin acción**, **GIF**, **Imagen** o **Video**.
- Pega un enlace público directo HTTPS a la imagen o al archivo .mp4/.webm.
- Ajusta cuánto tiempo se mostrará (1–30 segundos).
- Tras el giro, el color ganador muestra su GIF o video en la fuente de juegos de TikTok Studio, con fondo transparente y ocultación automática.
- El video se reproduce silenciado para permitir autoplay en fuentes web.
- Se mantienen los premios de texto, Lunitas, probabilidades, espera entre giros y comandos.
- El mismo efecto se muestra tanto en los overlays locales como en los alojados en Railway.
- Las pruebas verifican que no se reinicie el medio al refrescar y que no se acepten direcciones locales o javascript:.

**Nota:** los archivos son enlaces directos HTTPS; enlaces a páginas de YouTube o TikTok no son archivos de video reproducibles. Algunos proveedores externos prohíben incrustar contenido, así que usa un alojamiento compatible con enlaces directos. La selección de archivos locales para subirlos automáticamente no se incluye en esta versión.
