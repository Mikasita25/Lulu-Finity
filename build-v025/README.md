# Lulu Finity 0.25.0

Esta actualización conserva la interfaz existente de Lulu Finity 0.24.0 y reorganiza únicamente lo solicitado:

- Miku Classic usa la ilustración turquesa elegida.
- Miku Soft usa la ilustración rosa elegida.
- Miku Dark usa la ilustración morada elegida.
- `Cuenta` administra el enlace de la sesión local de TikTok.
- Los mensajes automáticos pasan a `Comandos`.
- YouTube y Spotify aparecen bajo una sola categoría visible: `Música`.
- `Rankings` cambia su nombre visible a `Overlays`.
- La transparencia de paneles puede bajarse hasta 20% para ver mejor las ilustraciones de fondo.
- `Sobre Lulu` usa la nueva ilustración con lentes elegida por el usuario.

Los overlays mostrados en OBS/TikTok LIVE Studio mantienen sus estilos propios y no reciben el fondo de Miku.
