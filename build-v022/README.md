# Lulu Finity 0.22.0

Este parche se aplica después de reconstruir Lulu Finity 0.21 desde la fuente 0.20.

Incluye:

- Medidor diario compartido con límite configurable de 7500 usos y estimación de 2 usos por conexión.
- Bloqueo de anuncios y promociones dentro del navegador integrado de YouTube.
- Temas Rosa claro, Morado, Rojo y Azul, además de Rosa original y Oscuro.
- Texto simplificado para la conexión de TikTok LIVE, sin mostrar Railway al usuario.

El workflow valida la sintaxis de Electron, las pruebas del relay y el contenido final de `app.asar` antes de publicar.
