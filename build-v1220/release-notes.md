# Lulu Finity 1.2.2

Esta actualización añade el control de volumen que faltaba en **Automatizaciones / Acciones**.

- Cada acción de tipo **Sonido** tiene ahora su propia barra de volumen de 0% a 100%.
- El porcentaje cambia en tiempo real mientras mueves la barra.
- El valor queda guardado dentro de esa acción y se reutiliza cada vez que se ejecuta.
- Funciona con acciones disparadas por regalos, likes, follows, suscripciones, comentarios y demás eventos compatibles.
- Las reglas creadas antes de esta actualización conservan compatibilidad y usan 90% si todavía no tenían un volumen guardado.
- Ajustar el volumen de una acción no modifica Música, TTS ni otros efectos.
- Mantiene las correcciones de estabilidad musical y del actualizador incluidas en 1.2.1.
