Privacidad al vincular TikTok

Tu cuenta se abre dentro del sitio oficial de TikTok. Vincularla no significa entregar tu cuenta a Lulu Finity ni al servidor de Lulú.

CONEXIÓN CON EL SERVIDOR DE LULÚ FINITY

La única finalidad del servidor de Lulú es la API WebSocket del LIVE

Cuando conectas un LIVE, la aplicación abre una conexión cifrada WSS (WebSocket seguro) con el relay de Lulú Finity. Esa conexión existe únicamente para operar las APIs de WebSocket que reciben en tiempo real comentarios, regalos, likes, seguidores, compartidos y otros eventos públicos del LIVE.

El relay también protege las claves técnicas del proveedor para que nunca tengan que incluirse dentro de la aplicación. La consulta del contador de uso pertenece al mismo servicio WebSocket. El inicio de sesión y la sesión de tu cuenta de TikTok no pasan por este servidor.

Tu PC WSS cifrado Relay de Lulú Eventos LIVE API del LIVE
LO QUE SÍ USA EL WEBSOCKET

Solo lo necesario para escuchar el LIVE

  • El nombre de usuario público del LIVE que quieres conectar.
  • Los eventos públicos que la API devuelve mientras el LIVE está activo.
  • Datos técnicos temporales de conexión, como dirección IP y hora, necesarios para seguridad, límites y funcionamiento de cualquier servicio de Internet.
  • Un contador general de conexiones para controlar la cuota del servicio.

El relay reenvía los eventos a tu aplicación en tiempo real; su código no crea una base de datos con tus comentarios, regalos o espectadores.

LO QUE NUNCA SE ENVÍA AL SERVIDOR DE LULÚ

Tu cuenta permanece fuera del relay

  • Tu contraseña, correo electrónico o número de teléfono.
  • Cookies de TikTok, sessionid, tokens o credenciales de acceso.
  • El contenido de tu computadora, archivos, micrófono, cámara o ubicación.
  • Tus ajustes de voces, reglas, comandos o configuración local.
  • Los textos enviados al chat o a una voz TikTok: esos van directamente a TikTok.

Railway no recibe tu sesión. Lulu Finity tampoco imprime contraseñas, cookies ni tokens de TikTok en sus archivos de registro.

SI EL SERVIDOR FUERA ATACADO

El relay no tiene permisos para leer datos de la aplicación

Lulu Finity trata al servidor como una fuente no confiable. El canal de mensajes WebSocket es de recepción: la app no contiene una respuesta que permita al relay solicitar cookies, sesión, archivos, ajustes, credenciales ni información del dispositivo.

Solo se aceptan tipos exactos de eventos públicos del LIVE y únicamente sus campos necesarios. Solicitudes remotas, RPC, comandos, métodos, canales IPC, campos privados, paquetes binarios, redirecciones y cargas excesivas se rechazan. Si el servidor intenta pedir datos o repite mensajes inválidos, Lulu corta esa conexión.

Un relay comprometido todavía podría interrumpir el servicio o fabricar un evento público, haciendo que TTS, alertas u otras funciones configuradas reaccionen como si fuera real. No puede usar el protocolo para leer datos locales: el proceso principal filtra el mensaje antes de que llegue a la interfaz y la sesión de TikTok permanece en una partición aislada.

A DÓNDE SE CONECTA CADA FUNCIÓN

Conexiones separadas y fáciles de entender

TikTok oficial Inicio de sesión, envío de mensajes y voces TikTok. La comunicación es directa con dominios oficiales de TikTok.
Servidor de Lulú Finity Únicamente el relay y estado técnico de la API WebSocket del LIVE; nunca autentica tu cuenta.
Microsoft Solo recibe el texto que eliges convertir en audio cuando usas una voz Microsoft online. No recibe tu sesión de TikTok.
Tu computadora Guarda la sesión aislada, ajustes, comandos y voces locales. Estos datos permanecen en el perfil de Windows de Lulu Finity.
SESIÓN LOCAL Y PERMISOS

La vinculación queda bajo tu control

La ventana de inicio de sesión está aislada del resto de la aplicación, muestra el dominio oficial y bloquea cámara, micrófono, ubicación, notificaciones y descargas. La sesión se guarda únicamente en el perfil local de Lulu Finity para que no tengas que iniciar sesión cada vez.

Cerrar la ventana conserva la sesión local. El botón de abajo elimina cookies, caché y almacenamiento local de TikTok de esta computadora. Después de borrarla, las voces Microsoft, Windows y Lulu Local continúan funcionando sin una cuenta.

Tú conservas el control Cerrar la ventana no borra la sesión. Usa “Desvincular y borrar sesión” para eliminar cookies, caché y almacenamiento local de TikTok de esta PC.

Lulu Finity no está afiliada con TikTok. Las voces TikTok usan una interfaz no oficial que puede cambiar; las voces Microsoft permanecen disponibles sin esta cuenta.
