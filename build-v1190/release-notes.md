# Lulu Finity 1.1.9

Esta actualización añade control de volumen individual a los sonidos de **Automatizaciones / Acciones**.

- Cada acción de tipo **Sonido** muestra una barra de volumen de 0% a 100%.
- El porcentaje se actualiza mientras mueves la barra.
- El valor queda guardado dentro de esa acción.
- Las acciones activadas por regalos, likes, follows, suscripciones, comentarios y demás eventos usan su propio volumen.
- Las configuraciones antiguas siguen funcionando y usan 90% cuando todavía no tenían un valor guardado.
- Ajustar una acción no cambia el volumen de Música, TTS ni otros sonidos.

No modifica la forma en que se detectan los regalos o eventos; solamente añade el control que faltaba sobre el audio de cada acción.
