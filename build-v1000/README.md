# Lulu Finity 1.0.0

Este paquete reconstruye la versión 1.0.0 sobre la fuente oficial 0.34.2.

## Contenido

- Interfaz agrupada por tareas y búsqueda global de funciones.
- Lulu Local con `sherpa-onnx-node`, proceso de utilidad aislado y paquetes `.lfvoice`.
- Limpieza Unicode, nombres sin emojis, bloqueo CJK y diccionario de pronunciación.
- Carga diferida de módulos y panel de rendimiento.
- Pruebas de interfaz, sandbox, juegos, automatizaciones, relay y texto inteligente.

La voz incluida se descarga durante el release desde el proyecto oficial `k2-fsa/sherpa-onnx` y se verifica con SHA-256 antes del empaquetado.
