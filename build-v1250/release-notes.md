Lulu Finity 1.2.5

- Actualización de la aplicación para el servidor Railway actualmente en producción.
- La conexión de TikTok LIVE, el contador de uso y las fuentes HTTPS utilizan una dirección base compartida, sin pedir enlaces a los usuarios.
- Se conservan las configuraciones de la versión anterior, las funciones de economía, las voces, los widgets y la ruleta de ocho colores.
- Publicación de instalador de Windows, ZIP y metadatos latest.yml para el sistema de actualizaciones.

Las instalaciones anteriores detectan la nueva versión mediante el actualizador integrado al comprobar GitHub. Las copias portables ZIP deben descargar la versión nueva manualmente.
