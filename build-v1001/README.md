# Lulu Finity 1.0.1

Hotfix sobre la fuente oficial 1.0.0.

- Repara la carga de voces Microsoft/online cuando Lulu Local está seleccionada.
- Obtiene automáticamente todas las voces gratuitas compatibles del catálogo online.
- Agrupa voces por idioma y país y permite buscarlas por nombre, región y género.
- Guarda un catálogo local de respaldo y excluye idiomas CJK según la configuración acordada.
- Añade **Voz Oficial De Lulu Finity** con la muestra autorizada de siete segundos.
- Descarga OpenVoice V2 como motor local opcional, verifica su SHA-256 y lo libera de memoria junto con Lulu Local.
- El instalador normal no incluye el motor pesado: cada usuario lo descarga sólo si decide instalar esta voz.
