# Lulu Finity 0.24.0 — Temas Miku

Este parche parte de la fuente oficial `0.23.0` y añade tres temas seleccionables sin alterar la distribución ni los widgets del stream:

- **Miku Classic:** turquesa/cian sobre fondo oscuro.
- **Miku Soft:** rosa pastel con detalles turquesa.
- **Miku Dark:** morado oscuro, cian y brillo nocturno.

Las ilustraciones solo aparecen dentro de la aplicación. Los rankings, reproductores y demás enlaces que se agregan a OBS o TikTok LIVE Studio conservan su diseño independiente.

El workflow valida el hash de la fuente base, el parche, las tres ilustraciones SVG, la sintaxis JavaScript y el `app.asar` final antes de publicar la actualización automática.
