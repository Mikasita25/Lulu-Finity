Ruleta de Dedsafío con los ocho colores y la animación original del HTML a 960 × 960, sin reducción de texturas, con duración de 14,11 segundos y audio.

- En Juegos del LIVE, configura el premio de texto y las Lunitas de cada color, sus probabilidades (total 100%), el tiempo de espera por usuario o para todo el chat, y cuánto se muestra el premio.
- El streamer decide el costo por giro: 0 es gratis. Sin saldo suficiente no se cobra ni se inicia la animación. El costo se descuenta una vez y el premio económico se acredita por separado.
- El comando de ruleta sigue siendo editable. Basta con escribir `!ruleta`, sin apostar ni elegir un color.
- El resultado se sortea antes de publicar la animación y determina el color donde termina.
- Las cantidades de Lunitas se acreditan automáticamente. Los premios escritos se muestran como texto; los premios externos se entregan manualmente.
- La fuente web de Pantalla de juego queda transparente cuando no hay actividad y se oculta al terminar. Usa 960 × 960 en TikTok Studio u OBS.
- No se interrumpen giros activos. Los comandos repetidos no entregan otro premio. Las pruebas no modifican saldos.
